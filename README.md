# Sales & Profit Performance Analytics Dashboard (Power BI)

## Project Overview
This project focuses on analyzing sales, profit, customer, and product performance 
to support data-driven business decisions.

## Tools & Technologies
- Power BI

## 📊 Dashboard Highlights
- Sales & profit trends over time
- Category and product performance
- Customer contribution analysis
- Return rate and profitability insights

## Key Business Insights
- Revenue and profit show strong growth after mid-2021
- Accessories generate the highest order volume
- Revenue is concentrated in a few high-performing products
- Low return rate indicates good product quality
